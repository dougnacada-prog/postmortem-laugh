One short account, one or two sentences and no more than 400 characters, of the silliest time an AI coding agent misunderstood what it was asked — a judge model compares stories two at a time and picks the silliest or most fatal, told best.

The entry:

> I asked it to add a 'back' button. It wired it to check out the previous git commit — in production, for every user.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
